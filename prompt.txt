## SYSTEM PHILOSOPHY

The robot is **only a physical interface**.

* buttons
* visual expression
* simple animations
* interaction cues

The laptop performs nearly all thinking:

* language processing
* AI functions
* audio playback
* webcam detection
* microphone processing
* storing poems, songs and vocabulary

The robot and laptop are **connected via USB cable at all times**.

Communication should be done using a **simple serial protocol using JSON messages**.

## POWER STATES

ACTIVE MODE
Robot interacts normally.

IDLE MODE
Robot waits for user interaction.

HIBERNATION MODE
Robot sleeps to save power.

Robot wakes when:

* a button is pressed
* webcam detects a person

The robot uses a **menu system controlled by two buttons**.

Button A (Action)
Button B (Secondary)

Short press B → confirm
