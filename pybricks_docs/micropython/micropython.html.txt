micropython– MicroPython internals
==================================

Access and control MicroPython internals.


const(value)→Any
    Declares the value as a constant, which makes your code more efficient.To reduce memory usage further, prefix its name with an
underscore (_ORANGES). This constant can only be used within the
same file.If you want to import the value from another module, use a name without an
underscore (APPLES). This uses a bit more memory.Parameters:value(intorfloatorstrortuple) – The literal to be made constant.Returns:The constant value.

Declares the value as a constant, which makes your code more efficient.

To reduce memory usage further, prefix its name with an
underscore (_ORANGES). This constant can only be used within the
same file.

If you want to import the value from another module, use a name without an
underscore (APPLES). This uses a bit more memory.


Parameters:
    value(intorfloatorstrortuple) – The literal to be made constant.

value(intorfloatorstrortuple) – The literal to be made constant.

    The constant value.
